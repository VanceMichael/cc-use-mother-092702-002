# 专业身份授权与数字人登记

管理专业身份数字人的授权范围、有效期、撤销和平台绑定。

## 参与方与事实

主要参与方包括医疗机构、执业人员、数字人制作方、平台资质审核人员。领域资料记录以下事实：

- 原生数字人没有真实生理体验
- 仿冒医生形象会放大消费者对专业建议的信任
- 医疗广告身份和代言资格需要真实责任依托

## 业务边界

- 执业资质
- 授权范围
- 肖像与声音许可
- 有效期
- 撤销影响

当前资料按以下边界组织：

- 人员资质档案
- 数字人身份登记
- 授权令牌
- 平台绑定
- 撤销传播

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/identity_context.py` 负责读取和校验资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

命令只读取仓库内文件，不需要连接外部业务系统。
